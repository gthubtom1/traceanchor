# 四方研究的必要摘要

研究日期：2026-11-18。以下是重新撰写的机制摘要，非报告原文或运行证明。所有来源提交、许可层、固定源码链接见 [baselines.json](baselines.json) 与 [mechanisms.json](mechanisms.json)。原研究完成专题阅读与选择性语义核验，未运行四方程序、安装器、测试、样本或 provider；未对四方进行同模型/同预算效果评测。

## Reverse

研究对象具备按需知识路由、案件范围、引用和阶段交接的组织方法。机械引用闭合与语义有效性分开，是吸收的重要原则。路由、脚本和文档标准并非始终由同一个执行权威落实；工具注册、路径存在和就绪不是同一件事。TraceAnchor 学习有限验收、不同源双侧运行、负控和失效规则，独立实现状态与效果检查；不复制技能文本，不依赖原 router，也不继承外部官方验收器的完成权威。关联 TA-003/005/007/009。

## REA

研究对象采用共享 CLI/MCP 应用链、来源身份、证据 authority/confidence、覆盖与未知项。部分接口评价的是已有证明或比较材料，而不是在接口调用当刻运行所有业务实验。TraceAnchor 学习分层和证据身份，但由自己的执行器和比较器生产实际验收；不将输入声明、摘要一致或命令文本当成本地已执行事实。五个 gitlink 仅清点身份，没有获取/审阅递归内容。关联 TA-001/002。

## Craft

研究对象的迭代工作流、检查复用、进程监督与取消可定位到实现，而非只有提示。基础运行成功、检查的完整质量和最终行为等价仍是不同命题；视觉、构建、候选自报不能独立证明业务正确。TraceAnchor 学习迭代、资源归属和 freshness 的问题框架，改用五个独立维度、完整输入绑定和有界 MCP 并发。未复制 Rust 实现、内部模型循环、提示词、图标或品牌。关联 TA-003/004/005/006。

## Seep

研究对象包含宿主接线、方法组织、多种工具封装及专项流水线。项目接线与服务真实就绪、字节写后回读与业务验证、稳定启动与修改生效，应各自裁决。TraceAnchor 学习薄接线和回读原则，独立实现回执所有权、失败传播与原件/派生/候选隔离，不带入嵌入的上游镜像、凭据类材料或二进制。外层来源提交确定，但某些嵌入镜像及 Web 素材的来源/许可缺口保持未知。关联 TA-006/007/008/009。

## 原创与范围

L1/L2/L3 生命周期、三种独立基线及默认静态复评治理、多目标观测缺口与有限开发子任务的冻结产品合同，作为本地原创需求设计标注，不声称四方已有同等实现。映射描述设计影响而非兼容义务；首版未承诺的一般桌面/Android/浏览器动态控制、反编译器与真实宿主流程，仍需对应资格测试后扩展支持声明。
