## L1 归档与 L2/L3 回收

1. 创建 material 登记：项目/任务/版本、来源、生成操作、tier/reason、hash、size、依赖/共享引用、活跃租约、恢复用途、再生成成本和 pin。
2. 归档 L1：精确提交、公开固定 blob 链接、相对路径/行/符号、必要最小摘要或经筛查摘录、内容/证据完整性摘要、映射/决策及回归设计。避免依赖会删除的临时绝对路径。
3. L1 验证：摘要校验结果、引用闭包、覆盖与未知仍可理解、恢复材料足够、无私密路径/凭据/完整报告。记录 archive_id 与 verified result。
4. L3 仅在 producer terminal、租约释放、无证据/恢复/共享引用后候选；L2 另需项目明确验收、L1 归档通过、依赖/恢复检查通过。L1、pinned、未知归属全部保留。
5. 只读 preview：每项 keep/delete 原因、预计字节、边界/link/hardlink 检查、数量/时间预算。preview 不是删除授权。
6. 若本次用户另有清理授权，执行前重查引用/租约/字节身份；有界、可取消、最小审计；中断记录 tombstone/recovery cursor，保留恢复点。清理失败不毁证据。
7. 清理后复核：L1 引用和结论仍可追溯，实回收字节、保留项、失败项和下一步。无清理授权时状态 not-run；不因复评完成自动删除原始历史或用户项目。
